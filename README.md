# Nexoraaifc

Crie um site SaaS profissional chamado Nexora AI, uma plataforma de inteligência artificial para empresas.

Objetivo: oferecer ferramentas de IA para automatizar atendimento, vendas e tarefas empresariais.

Design:

* Visual premium, moderno e minimalista.
* Fundo preto azulado (#0B1020).
* Detalhes verde tecnológico (#16C7B0).
* Textos brancos e cinza.
* Animações suaves e responsividade total.
* Interface inspirada em startups SaaS.

Página inicial:

* Logo Nexora AI.
* Menu: Início, Soluções, Preços, Login.
* Título: “Sua empresa mais inteligente começa aqui.”
* Subtítulo: “Automatize processos, atenda clientes e aumente resultados com inteligência artificial.”
* Botão: Começar gratuitamente.
* Demonstração visual de um chatbot.

Funcionalidades:

1. Chatbot inteligente para atendimento 24 horas.
2. IA para responder dúvidas de clientes.
3. Automação de mensagens.
4. Assistente para vendas.
5. Geração de textos comerciais.
6. Painel de controle com estatísticas.

Dashboard:

* Conversas realizadas.
* Clientes atendidos.
* Taxa de resolução.
* Histórico de conversas.
* Configurações do chatbot.

Planos:

* Grátis: recursos básicos.
* Pro: automações avançadas.
* Business: recursos completos para empresas.

Requisitos técnicos:

* Criar interface funcional e responsiva.
* Navegação entre páginas.
* Autenticação de usuários.
* Banco de dados.
* Preparar integração com API de IA.
* Não simular integrações reais como se já estivessem funcionando.

Priorize código limpo, carregamento rápido, baixo consumo de recursos e uma experiência simples.

O resultado deve parecer um produto SaaS real, pronto para evoluir comercialmente.
